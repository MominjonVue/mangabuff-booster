# MangaBuff Шахта

Chrome-расширение для `mangabuff.ru`. Функции:

- **⛏️ Шахта** — счётчик руды + ударов, авто-фарм и обмен. **Работает фоном** (service worker, `background.js`): удары `POST /mine/hit` идут строго по одному с паузами ~0,65–1,3 с (как анимация удара на сайте) и короткими «передышками» каждые 18–32 удара — параллельные запросы сервер в основном отбивает. На 429 ждём `Retry-After`, на прочие ошибки — экспоненциальный бэкофф и пересинхронизация ударов со страницы `/mine`; после 8 ошибок подряд стоп. Длинные паузы — через `chrome.alarms`, плюс сторожевой alarm раз в 30 с перезапускает цикл, если Chrome усыпил SW. Обмен (`POST /mine/exchange`, `diamonds=N`) меняет всю руду на максимум алмазов (100 руды = 1 💎).
- **📺 Реклама** (кнопка во вкладке «Шахта») — бонус за просмотр рекламы (сейчас на ивенте — конфеты), 3 раза в сутки. На сайте это Яндекс-блок `rewarded`, чей клиентский колбэк `onRewarded` делает голый `POST /balance/ads` без токена — расширение делает тот же POST фоном, **не загружая рекламу**, с паузами 32–55 с как у реального просмотра (через `chrome.alarms`). Счётчик за сегодня — `data-count` у кнопки `.user-quest__watch-ads-btn` на `/balance`. Отказ сервера (4xx, напр. лимит) — стоп без ретраев.
- **💬 Альянс** — авто-комментарии (`POST /comments`, 13 в день за алмазы). Цель находится сама: на главной ищется пункт меню «Мой альянс» (`/alliances/{id}`), запасной вариант — «Мой клуб»; тип и id берутся из блока `<div class="comments" data-type="ClubAlliance" data-id="…">` на этой странице, так что смена разметки/типа не ломает постинг. **Работает фоном** — цикл живёт в service-worker'е и продолжается когда попап закрыт; при следующем открытии попап показывает лог фона и сам переключается на вкладку если фарм идёт. Реальный счётчик берётся со страницы `/balance` (`Комментарии <b>N/13</b>`). День сбрасывается по **Москве** (`Intl.DateTimeFormat` с `Europe/Moscow`). **Не флудит:** первый коммент — корневой, остальные 12 — ответы (`parent_id`) на него же, всё в одной ветке. Текст: короткое слово + 5 символов UUID — никогда не повторяется. Серверный кулдаун ~30с, делаем 35–45с с джиттером через `chrome.alarms` (переживает рестарт SW). На 422 спим 35с и ретраим. rootId в `chrome.storage.local` — частичный ран продолжает ту же ветку (при смене альянса ветка начинается заново).
- **🎨 Скины** — все 44 скина из `/products/profileskin` с превью настоящих градиентов. Применяется **только на странице профиля** (`/users/*`). Сохраняется + ставится автоматически при заходе на профиль. Защита от стирания: MutationObserver следит за `body.class` и переустанавливает класс если сайт его убрал во время навигации.
- **👤 Аватар** — 756 готовых аватаров из `/products/avatar` + кнопка «Загрузить свою» (любая картинка ≤ 4 МБ, хранится локально как data-URL). Подменяет `img.my-avatar` **на всех страницах сайта**. Тоже под защитой обзёрвера от ре-рендера.
- Поиск аватаров по ID.
- **🛡 Блок** — `declarativeNetRequest` блокирует трекеры на mangabuff: GTM, Google Analytics, Яндекс.Метрика (`mc.yandex.ru`), `yandex.ru`, `yastatic.net`, DoubleClick, AdFox и др. Скоупится по `initiatorDomains: ["mangabuff.ru"]` — другие сайты не задеваются. Тумблер в попапе вкл./выкл. через `chrome.declarativeNetRequest.updateEnabledRulesets`.

## Установка

1. `chrome://extensions` → включи **Режим разработчика**.
2. **Загрузить распакованное** → выбери папку `Farmer/`.
3. Залогинься на `mangabuff.ru` в Chrome.

На Android — `.zip` ставится в **Kiwi Browser** / **Yandex Browser**.

## Файлы

```
manifest.json
icons/                — иконка-камень 16/32/48/128
popup/
  popup.html/.css/.js — UI (5 вкладок: Шахта / Альянс / Скины / Авка / Блок)
  skins-data.js       — 44 градиента
  avatars-data.js     — 756 ID аватаров
rules/
  trackers.json       — declarativeNetRequest правила блокировки трекеров
content/
  skin.js             — применяет скин на /users/* + защита от стирания
  avatar.js           — подменяет img.my-avatar на всём сайте + защита
background/
  background.js        — service worker: фоновые циклы шахты, комментов и бонуса за рекламу (chrome.alarms)
```

## Что важно понимать

- **Всё видно только тебе.** Ничего не покупается, не сохраняется на сервере, другие пользователи на твоём профиле увидят твой настоящий скин/аватар.
- **Чисто косметическая примерка**: меняем CSS-класс body и `src` у `img.my-avatar`. Сетевые запросы к серверу не модифицируются.
- Скин #44 на сайте использует пользовательские CSS-переменные — превью в попапе показывает условный градиент.
